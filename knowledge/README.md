# Frog knowledge base

Every `.md` or `.txt` file in this folder is indexed by Frog Copilot at start-up, one chunk per `##` section.

## What to add here

- SOPs from Frog Space (Bookshelf): opening and closing, cash-up, Club Frog split bills, staff discount, darts.
- Software guides for the tools the pubs use every day: Zelty, Nepting, Yokitup, Trail, Combo, Zenchef, BookingShake, SimplyBook, OBY Pay, Yooz.
- Supplier agreements and negotiated price lists, HR rules (Navigo, leave), menu launch checklists.

## How to write a document

- Start with a `# Title`, then one `##` section per topic: the Copilot cites the section title as its source.
- Keep one procedure per section and write the steps in order.
- Export PDFs or Word files to Markdown or text before adding them. After adding a file, restart the server (`npm start`) to re-index.

The two audit documents (`ClubFrog - Zuri.md` and `Frog Pubs Process Map.html`) in the parent folder are indexed automatically.
